# Secure Connect для Steam Deck (Decky Loader)

Плагин для [Decky Loader](https://decky.xyz): в игровом режиме (Game Mode) в меню
быстрого доступа (кнопка «…») можно выбрать профиль v2rayN Secure Connect и
подключиться — профиль запускается на **sing-box в режиме TUN**, через туннель идёт
весь трафик Deck.

Внутри плагина лежит Linux-версия приложения (`bin/v2rayN`) с ядрами. Профили,
подписки, маршруты и раздельное туннелирование настраиваются в самом приложении в
режиме рабочего стола (Desktop Mode) — плагин берёт те же профили и настройки.

> Статус: тестовая версия. Kill switch на Steam Deck пока нет.

## Как это работает

```
Game Mode, меню Decky ──► бэкенд плагина (root)
                            │ 1. v2rayN --decky config <профиль>   (от пользователя deck)
                            │    → sing-box-конфиг с TUN, маршрутами, split tunneling
                            └ 2. sing-box run -c …  (root — нужен для TUN)
```

- Данные приложения — в `~/.local/share/v2rayN` (а не в папке плагина), поэтому
  обновление плагина профили не стирает.
- Выбранный в плагине профиль становится активным и в приложении.
- Журнал ядра: `sing-box.log` в папке плагина в `~/homebrew/logs/`.

## Установка

1. Decky Loader → Настройки → **Режим разработчика** (Developer mode) → включить.
2. Скопировать `v2rayN-steamdeck_test.zip` на Deck (например, в `~/Downloads`).
3. Decky → Настройки → Developer → **Install Plugin from ZIP File** → выбрать zip.
   Или «Install Plugin from URL», если zip лежит по ссылке (например, в релизе на GitHub).
4. Перейти в режим рабочего стола: в меню приложений появится
   **Secure Connect (v2rayN)** — добавить профили (импорт из буфера, подписки),
   при желании настроить маршруты и раздельное туннелирование. TUN в самом
   приложении не нужен — его включает плагин: если приложение спросит пароль для
   TUN, нажмите «Отмена».
5. Вернуться в игровой режим → «…» → значок щита → выбрать профиль → **Подключить**.

## Обновление

Перед установкой новой версии лучше отключиться в плагине. Затем — тот же пункт
«Install Plugin from ZIP File». Профили и настройки лежат в `~/.local/share/v2rayN`
и при обновлении не теряются.

## Если что-то не так

- Текст ошибки показывается прямо в панели плагина.
- Журналы sing-box (`sing-box.log`) и самого плагина — в его папке в `~/homebrew/logs/`.
- Журнал приложения: `~/.local/share/v2rayN/guiLogs/`.
- Профиль, который sing-box не поддерживает (например, транспорт xhttp), не
  подключится — ошибка будет в панели.

## Сборка (Windows)

Нужны .NET 10 SDK, Node.js 18+ и pnpm (`npm install -g pnpm`).

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build-decky.ps1            # → dist\v2rayN-steamdeck_test.zip
```

Скрипт собирает Linux-версию с ядрами (`build-release.ps1 -Targets linux-x64`),
интерфейс плагина (`decky/src`, pnpm + rollup) и пакует всё в
`SecureConnect/…` с путями через `/`.
