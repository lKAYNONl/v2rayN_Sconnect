# Secure Connect для Steam Deck (Decky Loader)

Плагин для [Decky Loader](https://decky.xyz): в игровом режиме (Game Mode) в меню
быстрого доступа (кнопка «…») можно выбрать профиль v2rayN Secure Connect и
подключиться — профиль запускается на **sing-box в режиме TUN**. Там же выбирается,
что идёт через туннель: весь Deck, только выбранные приложения или всё, кроме
выбранных, — приложения добавляются из списка запущенных процессов.

Внутри плагина лежит Linux-версия приложения (`bin/v2rayN`) с ядрами. Профили и
подписки добавляются в самом приложении в режиме рабочего стола (Desktop Mode).
Профили, список раздельного туннелирования и правила маршрутизации у плагина и
приложения общие.

> Статус: тестовая версия. Kill switch на Steam Deck пока нет.

## Как это работает

```
Game Mode, меню Decky ──► бэкенд плагина (root)
                            │ 1. v2rayN --decky config <профиль>   (от пользователя deck)
                            │    → sing-box-конфиг с TUN, маршрутами, split tunneling
                            └ 2. sing-box run -c …  (root — нужен для TUN)
```

IPv6 мимо туннеля не уходит: у туннеля всегда есть IPv6-адрес, и если IPv6 в
настройках TUN выключен (так по умолчанию), sing-box сразу отклоняет IPv6-соединения —
приложения переходят на IPv4 через туннель. Если система не даёт добавить IPv6-адрес,
плагин включает `strict_route`, и IPv6 просто недоступен.

Режим и список меняются через `v2rayN --decky split` / `split-set` — это те же
настройки, что в приложении (ROUTING → раздельное туннелирование, «Правила
маршрутизации»). При подключённом туннеле любое изменение сразу переподключает его
(на 2–3 секунды).

- Данные приложения — в `~/.local/share/v2rayN` (а не в папке плагина), поэтому
  обновление плагина профили не стирает.
- Выбранный в плагине профиль становится активным и в приложении.
- Журнал ядра: `sing-box.log` в папке плагина в `~/homebrew/logs/`.

## Установка

1. Decky Loader → Настройки → **Режим разработчика** (Developer mode) → включить.
2. Скопировать `v2rayN-steamdeck_test.zip` на Deck (например, в `~/Downloads`).
3. Decky → Настройки → Developer → **Install Plugin from ZIP File** → выбрать zip.
   Или «Install Plugin from URL», если zip лежит по ссылке (например, в релизе на GitHub).
4. Перейти в режим рабочего стола: в меню приложений появится
   **Secure Connect (v2rayN)** — добавить профили (импорт из буфера, подписки),
   при желании настроить маршруты и раздельное туннелирование. TUN в самом
   приложении не нужен — его включает плагин: если приложение спросит пароль для
   TUN, нажмите «Отмена».
5. Вернуться в игровой режим → «…» → значок щита → выбрать профиль → **Подключить**.

## Что идёт через туннель

В панели плагина, раздел «Что идёт через туннель»:

| Режим | Что происходит |
|---|---|
| **Весь Deck** | весь трафик — игры Steam, сторонние игры, браузер, сам Steam. Список приложений сохраняется, но не действует. Этот режим есть только в плагине |
| **Только выбранные** | через туннель идут только приложения из списка, остальное — напрямую. Пустой список (и нет подсетей, заданных в приложении) = весь Deck |
| **Всё, кроме выбранных** | приложения из списка идут напрямую, остальное — через туннель |

**Правила маршрутизации** — выкл: весь трафик туннеля идёт через прокси, правила набора
маршрутизации (например, «локальные сайты напрямую») не действуют; напрямую остаётся
только локальная сеть, а QUIC (UDP 443) блокируется — браузеры переходят на TCP.

**Добавить запущенное…** — список процессов, которые сейчас работают, с поиском.
Сначала идут те, что пользуются сетью (`● в сети`). Отметьте нужные и нажмите
«Добавить выбранные». Удобнее всего запустить игру, вернуться в меню «…» и добавить её.

Как распознаются приложения (sing-box определяет программу по файлу процесса,
`/proc/<pid>/exe`, и плагин показывает ровно то, что увидит sing-box):

- **Игры на Proton / Wine** (в том числе сторонние, добавленные в Steam как «Non-Steam
  game») — у них виден не `.exe` игры, а загрузчик Wine (`wine64-preloader`), а сетевые
  соединения держит ещё и `wineserver`. Поэтому в список попадает **версия Proton
  целиком** (папка вроде `…/common/Proton 9.0 (Beta)/`): через туннель пойдут все игры
  на этой версии. Нужна одна игра — назначьте ей в Steam (Свойства → Совместимость)
  отдельную версию Proton (например, GE-Proton) и добавьте её. Для Wine, установленного
  в систему, добавляются его загрузчик и `wineserver`.
- **Flatpak-приложения** (браузеры, Discord и т. п. из Discover) — путь внутри песочницы
  (`/app/…`), подпись — id приложения.
- **AppImage** — по имени файла (путь `/tmp/.mount_…` меняется при каждом запуске).
- **Обычные Linux-игры и программы** — полный путь к файлу.
- **Скрипты** (Python, Java и т. п., например Lutris) — sing-box видит интерпретатор,
  поэтому в список попадёт он, и совпадут все программы на нём; в списке это помечено.

## Обновление

Перед установкой новой версии лучше отключиться в плагине. Затем — тот же пункт
«Install Plugin from ZIP File». Профили и настройки лежат в `~/.local/share/v2rayN`
и при обновлении не теряются.

## Если что-то не так

- Текст ошибки показывается прямо в панели плагина.
- Журналы sing-box (`sing-box.log`) и самого плагина — в его папке в `~/homebrew/logs/`.
- Журнал приложения: `~/.local/share/v2rayN/guiLogs/`.
- Профиль, который sing-box не поддерживает (например, транспорт xhttp), не
  подключится — ошибка будет в панели.
- **Приложение висит или идёт мимо туннеля** — раздел «Проверка» в панели плагина:
  1. подключитесь и включите **«Подробный журнал»** (sing-box записывает каждое
     соединение: какая программа, куда, через прокси или напрямую);
  2. запустите приложение и дождитесь, пока оно зависнет;
  3. «…» → **«Проверить соединение»** (до 30 секунд). Итог показывается прямо в
     панели, полный отчёт сохраняется в `~/Desktop/secure-connect-diag.txt` (без
     ключей и адресов серверов).

  Что проверяется: уходит ли IPv6 мимо туннеля; не остался ли системный прокси
  `127.0.0.1:10808` от приложения в режиме рабочего стола (браузеры и
  Electron-приложения, например Discord, идут на него, а в игровом режиме там никто
  не слушает — кнопка «Сбросить системный прокси»); прокси в окружении Flatpak-
  приложений; DNS; открываются ли сайты; и по журналу — сколько соединений каждой
  программы ушло через прокси, сколько напрямую и с какими ошибками. После проверки
  подробный журнал лучше выключить.
- **Сторонняя игра или приложение идёт мимо туннеля:**
  1. режим «Весь Deck» — проверка, что туннель вообще работает для этой программы;
  2. «Правила маршрутизации» выкл — если адрес попадал под правило «напрямую»
     (так бывает с сервисами проверки IP);
  3. режим «Только выбранные» — программа должна быть в списке: запустите её и
     добавьте через «Добавить запущенное…». Для игры на Proton добавляется версия
     Proton — проверьте, что игра запущена именно на ней.

## Сборка (Windows)

Нужны .NET 10 SDK, Node.js 18+ и pnpm (`npm install -g pnpm`).

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build-decky.ps1            # → dist\v2rayN-steamdeck_test.zip
```

Скрипт собирает Linux-версию с ядрами (`build-release.ps1 -Targets linux-x64`),
интерфейс плагина (`decky/src`, pnpm + rollup) и пакует всё в
`SecureConnect/…` с путями через `/`.
